# Puppy's Home

Website giới thiệu dịch vụ chăm sóc thú cưng và quản lý nội dung, dịch vụ, bảng giá.

## Công nghệ

- Frontend: React, TypeScript, Vite
- Backend: Java, Spring Boot, REST API
- Database: MySQL
- Version control: Git
- API testing: Postman

## Trạng thái dự án

Đang trong giai đoạn khởi tạo môi trường và xây dựng nền tảng.

## Cấu trúc dự kiến

- `frontend/`: giao diện người dùng
- `backend/`: REST API và nghiệp vụ
- `docs/`: tài liệu thiết kế và hướng dẫn
